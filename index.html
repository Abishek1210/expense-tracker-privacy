Privacy Policy — Expense Tracker

Last updated: 27 October 2026

Expense Tracker is a personal expense-logging app built and used by a single individual (the developer). It is not distributed publicly and has no other users. This policy explains what data the app accesses and how it is used.

What data the app accesses

  • Google Sheets: the app reads and writes expense entries to a Google Sheet owned by the developer. This Sheet is the app's only database.
  • Gmail (read-only): the app scans the developer's own Gmail inbox for bank/UPI transaction emails, so they can be parsed and optionally logged as expenses. Email content is read on-device/in-app only, to extract amount, merchant and date — it is never stored, transmitted elsewhere, or shared.
  • Device SMS: on Android, the app reads incoming SMS messages to detect bank/UPI transaction alerts, for the same purpose as above.
  • Basic Google profile info (name, photo): shown in the app's own Profile screen.

What the app does not do

  • It does not share, sell, or transmit any of this data to any third party or external server.
  • It does not use the data for advertising, analytics, or any purpose other than logging the developer's own expenses.
  • It has no backend server of its own — the only destinations for any data are the developer's own Google Sheet and Google Account.

Data retention

Expense data persists only in the developer's own Google Sheet, for as long as the developer keeps it there. Parsed SMS/email content used to detect a transaction is not retained beyond what's needed to display it for review before logging.
